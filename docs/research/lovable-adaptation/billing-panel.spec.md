# Component spec: plan and usage

## Content

- Show only real state returned by `billing-status`.
- Free: one analysis per UTC day and a single upgrade action.
- Pro: $10/month, current Pro status, and a manage-subscription action.
- Do not invent charts, historical usage, credit balances, or team billing.

## Presentation

- Current plan and allowance share one two-column panel at wide widths.
- Plan badge uses existing blue/lilac; healthy availability uses green/mint.
- Billing errors render in the existing live status region and do not discard the last valid plan state.
