# Page topology

```text
Workspace shell
├── Persistent rail (desktop) / drawer (compact)
│   ├── Brand + research workspace label
│   ├── Work: New analysis
│   ├── Library: Conference library, Saved papers, Conversations
│   ├── Contribute: Submit a program
│   ├── Live corpus status
│   ├── Language
│   └── Account entry
└── Workspace content
    ├── Compact header (tablet/mobile only)
    ├── Analysis composer
    ├── Evidence workflow and report
    ├── Conference library
    ├── Saved papers
    ├── Conversations
    └── Program submission

Account dialog
├── Anonymous: provider-first authentication
└── Authenticated settings center
    ├── Account overview
    ├── Plan and usage
    ├── Research library
    └── Data and privacy
```

The structure adapts Lovable's public dashboard and settings hierarchy to Idea Radar's real routes and capabilities. It does not add unsupported search, team, project, or credit features.
